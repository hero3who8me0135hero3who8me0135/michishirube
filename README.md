# みちしるべ（ホーム画面アプリ版）

進路を考えるための伴走アプリです。スマホやタブレットのホーム画面に入れて、ネットなしでも使えます。

## 公開のしかた（GitHub Pages）

1. github.com にログインし、右上の「＋」→「New repository」を選ぶ。名前は `michishirube`、「Public」を選んで「Create repository」。
2. 「uploading an existing file」を押し、このフォルダの中身をすべてドラッグして「Commit changes」。
   中身は index.html、stories.json、manifest.webmanifest、sw.js、README.md と、fonts・icons の2つのフォルダです。
3. 「Settings」→「Pages」→「Branch」で `main` と `/ (root)` を選んで「Save」。
4. 1〜2分後、`https://ユーザー名.github.io/michishirube/` で公開されます。

## スマホ・タブレットに入れる

- Android：Chromeで公開アドレスを開き、「︙」→「アプリをインストール」（または「ホーム画面に追加」）。
- iPhone・iPad：Safariで公開アドレスを開き、共有ボタン→「ホーム画面に追加」。

一度アイコンから起動すれば、そのあとはネットなしでも動きます。

## 人物（ひとの物語）を追加するには

**方法A：アプリの中で追加（その端末だけ）**
「ひとの物語」の一番下の「人物を追加する」から入力します。その端末の中にだけ保存されます。

**方法B：stories.json に書き足す（全員の端末に反映）**
1. GitHubのリポジトリで `stories.json` を開き、右上の鉛筆マーク（Edit）を押す。
2. 最後の `}` のうしろに `,` を付けて改行し、次の形で1人分を書き足す。最後の行は `]` のままにする。

```
{"名前":"○○","分野":"音楽","時代":"今","愛媛四国":false,"説明":"ピアニスト（2000年〜）","はじめ":"…","つまずき":"…","その後":"…","ヒント":"…"}
```

- 分野は「音楽・アート・ことば・スポーツ・研究・仕事・表現・くらし」のどれか。
- 時代は「今」か「昔」。愛媛・四国ゆかりなら `true`。
- アプリで追加した人は「追加した人を書き出す（コピー）」で、この形の文字をコピーできます。

3. 「Commit changes」を押す。1〜2分後、ネットにつながった状態でアプリを開くと反映されます。

書き方をまちがえるとファイルが読めなくなり、アプリはもとから入っている人物で表示されます。
不安なときは、Claudeに「この人を stories.json に追加して」と頼めば、差し替え用のファイルを作ります。

## アプリ本体を直したとき

`index.html` などを差し替えたら、`sw.js` の3行目の `v1` を `v2`（以降 `v3`…）に変えてからアップロードしてください。

## 記録について

記録（調子・学習・気持ちノート・追加した人物）は、その端末の中だけに保存されます。
「おうちの人へ」画面の「データをコピー」で、ときどきバックアップしてください。

## 書体

BIZ UDPゴシック、Zen Maru Gothic、Yusei Magic（いずれも SIL Open Font License）を、使う文字に絞って同梱しています。ライセンス文は fonts フォルダにあります。
